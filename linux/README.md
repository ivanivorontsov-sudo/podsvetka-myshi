# Linux-версия «Подсветки мыши»

Отдельная Linux-реализация проекта «Подсветка мыши». Windows-версия в корне репозитория не изменяется.

## Возможности

- Мягкая цветная подсветка вокруг системного курсора.
- Красное кольцо при левом щелчке и синее при правом.
- Настройка цвета, размера и непрозрачности свечения.
- Настройка радиуса, толщины и длительности анимации щелчка.
- Выбор стиля щелчка: один круг без «паутины», двойная рябь или многослойная рябь.
- Режим показа подсветки только при движении мыши.
- Пропуск щелчков в приложения под прозрачным оверлеем.
- Не забирает фокус и не требует прав администратора.
- Пользовательский автозапуск через файл .desktop.
- Настройки сохраняются в ~/.config/podsvetka-myshi/settings.json.
- Журнал работы: ~/.local/state/podsvetka-myshi/app.log.
- Сетевые подключения не используются, телеметрии нет.

## Поддерживаемая среда

- **X11/Xorg:** поддерживаются прозрачная подсветка, пропуск щелчков и анимация левого/правого нажатия.
- **KDE Plasma Wayland (KWin):** координаты курсора поступают через пользовательский KWin script и D-Bus, свечение рисуется прозрачным окном XWayland. Анимацию нажатий рисует встроенный эффект KWin Mouse Click Animation: он получает реальные события кнопок и показывает анимированные кольца. Приложение настраивает число волн (1, 2 или 4), цвет, радиус, толщину и длительность. Режим «Одиночный импульс» рисует одно кольцо без многослойной «паутины». Эффект автоматически затухает; отдельная ручная настройка прозрачности кольца у системного эффекта KWin отсутствует. Непрозрачность свечения вокруг курсора регулируется отдельно.
- **Другие Wayland-композиторы** пока не поддерживаются.

### Исправления 1.1.3 — выбор анимации щелчка

- Добавлен список стилей: одиночный импульс (одно кольцо, без «паутины»), двойная рябь (2 кольца) и многослойная рябь (4 кольца).
- На KDE Wayland число волн передаётся во встроенный эффект KWin через `RingCount`, после чего эффект перенастраивается без перезапуска приложения.
- На X11 приложение рисует те же варианты самостоятельно, со сдвигом волн по времени.
- Новым настройкам назначен безопасный режим по умолчанию — одно кольцо. Сохранённые цвета, радиус, длительность и остальные параметры не сбрасываются.

### Исправления 1.1.2 для KDE Wayland

- Перед переключением анимации приложение запрашивает реальные зарегистрированные имена действий KWin через `KGlobalAccel.Component.shortcutNames()`. Это важно, поскольку `invokeShortcut()` молча игнорирует неизвестное имя.
- Выбирается фактически зарегистрированное действие `ToggleMouseClickAnimation` или старое `ToggleMouseClick`; при неоднозначности приложение показывает список имён вместо ложного сообщения об успешном вызове.
- Проверка свойства `enabled` принимает булевы значения в текстовом формате `true/false`, `1/0`, `yes/no` и `on/off`; нераспознанный ответ записывается в журнал целиком.

### Исправления 1.1.1 для KDE Wayland

- Исправлен запуск KWin cursor bridge: вместо вызова `loadScript(file, id)` с неподдерживаемой D-Bus-сигнатурой скрипт регистрируется как KPackage по `KPlugin.Id` из `metadata.json`.
- Приложение включает пакет через `Plugins/podsvetka-myshiEnabled`, вызывает `reconfigure()` и `Scripting.start()`, затем проверяет `isScriptLoaded("podsvetka-myshi")`. При выходе скрипт отключается и выгружается.
- Уточнена проверка Mouse Click Animation: состояние `enabled` читается из свойства эффекта через `/Effects supportInformation("mouseclick")`, а не из общего отчёта `/KWin`.

### Исправления 1.1.0 для KDE Wayland

- Перед включением приложение проверяет поддержку эффекта KWin и явно загружает плагин `mouseclick`.
- Состояние анимации читается через `/Effects supportInformation("mouseclick")` из свойства `enabled`; после команды KGlobalAccel приложение ждёт подтверждения KWin.
- Загрузка плагина и включение анимации больше не смешиваются: `toggleEffect("mouseclick")` не используется, поскольку он переключает загрузку плагина, а не состояние анимации.
- Стандартный радиус кольца уменьшен до 18 пикселей; значение прежнего стандартного радиуса 30 мигрирует при обновлении.
- В Wayland ручная прозрачность колец по-прежнему не поддерживается самим эффектом KWin: приложение прямо показывает, что затухание выполняет KWin автоматически.

В режиме KDE Wayland окно отрисовки использует XWayland, а глобальные координаты берёт у KWin. XWayland не используется для перехвата ввода.

## Установка из репозитория

На Debian/Ubuntu выполни:

    sudo apt update
    sudo apt install -y python3 python3-gi gir1.2-gtk-3.0 python3-cairo python3-gi-cairo python3-xlib python3-dbus xwayland
    git clone https://github.com/ivanivorontsov-sudo/podsvetka-myshi.git
    cd podsvetka-myshi
    bash linux/install.sh

После установки запусти «Подсветка мыши» из меню приложений или командой. Повторный запуск пункта меню открывает настройки уже работающего экземпляра:

    podsvetka-myshi

## Команды

    podsvetka-myshi              # запуск
    podsvetka-myshi --settings   # настройки работающей копии
    podsvetka-myshi --toggle     # включить/выключить подсветку
    podsvetka-myshi --quit       # завершить работу
    podsvetka-myshi --version    # версия

Некоторые конфигурации GNOME скрывают классические значки трея. Настройки при этом доступны из меню приложений или через команду --settings.

## Debian-пакет

GitHub Actions собирает пакет podsvetka-myshi_*_all.deb. Скачать его можно во вкладке Actions → Linux build → Artifacts, а для релизов с тегами v* пакет прикрепляется к GitHub Release.

Перед обновлением закрой уже работающую старую копию:

    podsvetka-myshi --quit

Установка локального пакета:

    sudo apt install ./podsvetka-myshi_*_all.deb

## Удаление

    bash linux/uninstall.sh

Настройки и журнал сохраняются. Их можно удалить вручную, если они больше не нужны. Удаление отключает пользовательский KWin script.
