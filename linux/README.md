# Linux-версия «Подсветки мыши»

Отдельная Linux-реализация проекта «Подсветка мыши». Windows-версия в корне репозитория не изменяется.

## Возможности

- Мягкая цветная подсветка вокруг системного курсора.
- Красное кольцо при левом щелчке и синее при правом.
- Настройка цвета, размера и яркости свечения, радиуса и длительности кругов.
- Режим показа подсветки только при движении мыши.
- Пропуск щелчков в приложения под прозрачным оверлеем.
- Не забирает фокус и не требует прав администратора.
- Пользовательский автозапуск через файл .desktop.
- Настройки сохраняются в ~/.config/podsvetka-myshi/settings.json.
- Журнал работы: ~/.local/state/podsvetka-myshi/app.log.
- Сетевые подключения не используются, телеметрии нет.

## Поддерживаемая среда

- **X11/Xorg:** поддерживаются прозрачная подсветка, пропуск щелчков и анимация левого/правого нажатия.
- **KDE Plasma Wayland (KWin):** поддерживается через официальный KWin scripting API для координат курсора и прозрачное окно XWayland для отрисовки. Нужны XWayland и `python3-dbus`. Первый запуск включает пользовательский KWin script; при штатном выходе он выключается. Анимация щелчков на Wayland отключена, поскольку используемый KWin scripting API передаёт координаты, но не состояние кнопок мыши.
- **Другие Wayland-композиторы** пока не поддерживаются.

В режиме KDE Wayland окно отрисовки использует XWayland, а глобальные координаты берёт у KWin. XWayland не используется для перехвата ввода.

## Установка из репозитория

На Debian/Ubuntu выполни:

    sudo apt update
    sudo apt install -y python3 python3-gi gir1.2-gtk-3.0 python3-cairo python3-gi-cairo python3-xlib python3-dbus xwayland
    git clone https://github.com/ivanivorontsov-sudo/podsvetka-myshi.git
    cd podsvetka-myshi
    bash linux/install.sh

После установки запусти «Подсветка мыши» из меню приложений или командой:

    podsvetka-myshi

## Команды

    podsvetka-myshi              # запуск
    podsvetka-myshi --settings   # настройки работающей копии
    podsvetka-myshi --toggle     # включить/выключить подсветку
    podsvetka-myshi --quit       # завершить работу
    podsvetka-myshi --version    # версия

Некоторые конфигурации GNOME скрывают классические значки трея. Настройки при этом доступны из меню приложений или через команду --settings.

## Debian-пакет

GitHub Actions собирает пакет podsvetka-myshi_*_all.deb. Скачать его можно во вкладке Actions → Linux build → Artifacts, а для релизов с тегами v* пакет прикрепляется к GitHub Release.

Установка локального пакета:

    sudo apt install ./podsvetka-myshi_*_all.deb

## Удаление

    bash linux/uninstall.sh

Настройки и журнал сохраняются. Их можно удалить вручную, если они больше не нужны. Удаление отключает пользовательский KWin script.
