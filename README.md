# Подсветка мыши

Маленькая программа для Windows 10/11: вокруг курсора **всегда** мягкая жёлтая подсветка, а при щелчке от курсора расходится тонкий круг: **красный** для левой кнопки, **синий** для правой.

* Начинает работать **сразу после запуска**, без переключателей и горячих клавиш.
* При первом запуске сама включает **автозапуск с Windows**, поэтому подсветка появляется после каждой загрузки. Выключить автозапуск можно в меню значка, и тогда программа больше его не включит.
* Один файл `PodsvetkaMyshi.exe` (~230 КБ), без установки и без прав администратора. Нужен .NET Framework 4.8: он уже есть в Windows 10 1903+ и Windows 11.
* Подсветка не мешает работать: щелчки проходят сквозь неё, она не забирает фокус, её нет в Alt+Tab и на панели задач.
* Правильно работает на нескольких мониторах с разным масштабом (Per-Monitor DPI v2): на мониторе со 150 % подсветка в 1,5 раза больше в пикселях и выглядит одинаково.
* Почти не нагружает компьютер: пока мышь стоит, программа «спит» и просыпается 10 раз в секунду на проверку. Во время движения и анимации она рисует до ~60 кадров в секунду.

## Меню значка в трее

| Пункт | Что делает |
|---|---|
| **Настройки…** | открывается и щелчком по значку |
| Автозапуск с Windows | через `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, без администратора и без Планировщика заданий |
| Открыть журнал | `%APPDATA%\PodsvetkaMyshi\log.txt` |
| Выход | |

## Настройки

Изменения видны **сразу** вокруг настоящего курсора. «ОК» сохраняет их, «Отмена» возвращает как было, «По умолчанию» сбрасывает.

* **Подсветка:** вкл/выкл, цвет, размер (20–400 пикс.), яркость в центре (5–100 %), показывать всегда или только пока мышь двигается.
* **Круг при щелчке:** отдельно для левой и правой кнопки (вкл/выкл и цвет), размер, длительность (150–3000 мс), толщина линии.
* **Прочее:** автозапуск; «Не показывать на скриншотах и записи экрана» (по умолчанию выключено, то есть подсветка видна в записи и демонстрации экрана); «Прятать подсветку, когда курсор скрыт».

Настройки хранятся в `%APPDATA%\PodsvetkaMyshi\settings.ini`, журнал там же, в `log.txt`.

## Защита от ошибок

* **Повторный запуск** не создаёт вторую копию: работающая программа покажет уведомление «уже работает». При автозапуске вторая копия молча закрывается.
* **Испорченный или вручную неправильно исправленный** файл настроек не ломает программу: неверные значения заменяются допустимыми с уведомлением, а испорченный файл сохраняется как `settings.ini.broken`.
* **Windows иногда «снимает» перехватчик мыши** у программ, которые долго отвечают. У нас перехватчик живёт в отдельном потоке и ничего не делает сам, поэтому не тормозит. Если Windows всё же снимет его, программа заметит это и поставит перехватчик заново. Пока перехватчика нет, курсор и щелчки отслеживаются опросом, так что подсветка не пропадает.
* Любая непредвиденная ошибка записывается в журнал, показывается короткое уведомление, а программа продолжает работать. Если сбоит отрисовка, она перезапускается сама.

## Если появилась ошибка оператора

Сообщение **«Оператор или администратор отклонил запрос» (0x800710E0)** в Windows 11 чаще всего выдаёт **Планировщик заданий**: задача «уже выполняется», компьютер спал, задача требует прав администратора, работы только от сети и т. п.

«Подсветка мыши» устроена так, чтобы этого не было:

* **Нет задач Планировщика.** Автозапуск сделан обычной строкой в `HKCU\...\Run`. Если вы раньше сами создавали задачу для этой программы, удалите её.
* **Не нужны права администратора** (манифест `asInvoker`), нет UAC-запросов.
* **Повторный запуск не «отклоняется»:** вторая копия просто передаёт команду первой.
* Если Windows выключила автозапуск в «Диспетчер задач → Автозагрузка», программа предупредит. Если снова выбрать «Автозапуск с Windows» в меню, запрет снимется.
* Если программа запущена прямо из архива (временная папка) или со съёмного диска, автозапуск не включается, потому что потом файла там не будет. Программа подскажет перенести exe в постоянную папку.

Что ещё может помешать запуску:

1. **SmartScreen** («Система Windows защитила ваш компьютер»): у exe нет цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае». Можно и заранее: «Свойства» файла → «Разблокировать».
2. **«Интеллектуальное управление приложениями» (Smart App Control)** в Windows 11 блокирует любые неподписанные программы, исключений для отдельных программ у него нет. Остаётся выключить его или подписать exe.
3. **Корпоративные политики** (AppLocker/WDAC).

## Ограничения

* **Окна, запущенные от имени администратора.** Обычная программа не получает события мыши над такими окнами (защита Windows UIPI). Подсветка там следует за курсором с помощью опроса, а круги при щелчке могут появляться с задержкой или не появляться. Если это нужно, запустите «Подсветку мыши» от имени администратора (автозапуск при этом всё равно запускает её обычной).
* **Полноэкранные игры в эксклюзивном режиме** выводят картинку мимо рабочего стола, поэтому подсветки поверх них не будет. В оконном и «безрамочном» режиме она есть.
* Некоторые системные элементы Windows 11 (меню «Пуск», центр уведомлений, экран блокировки, окна UAC) находятся выше любых обычных окон, и подсветка будет под ними.
* Панель задач иногда ненадолго перекрывает подсветку после щелчка по ней (до ¼ секунды), потом подсветка снова поверх.
* Подсветка видна на скриншотах (в том числе в «Быстром скрине») и в записи экрана. Если она там не нужна, включите «Не показывать на скриншотах и записи экрана» (Windows 10 2004+).
* Курсор рисует сама Windows, а подсветка — это окно, которое движется за ним, поэтому при очень резких движениях она может отставать на кадр.

## Для разработчика

```
PodsvetkaMyshi.exe               запуск (эффект включается сразу)
PodsvetkaMyshi.exe --settings    открыть настройки (в уже запущенной копии)
PodsvetkaMyshi.exe --quit        закрыть запущенную копию
PodsvetkaMyshi.exe --autostart   так запускает автозапуск (если уже работает — тихо выйти)
--config-dir папка               другая папка настроек (для тестов)
```

Как устроено: два окна `WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE | WS_EX_TOPMOST` (подсветка и круги поверх неё). Попиксельная прозрачность задаётся через `UpdateLayeredWindow`. Изображение подсветки рисуется один раз и при движении только сдвигается. Перехватчик `WH_MOUSE_LL` работает в отдельном потоке, отрисовка — в своём потоке с таймером высокого разрешения.

Сборка: `dotnet build -c Release` (.NET SDK 8+; проект net48 собирается и на Linux). Модульные тесты и дымовой тест с настоящими движениями мыши, щелчками и снимками экрана запускаются в GitHub Actions на `windows-latest`. При теге `v*` exe прикрепляется к релизу.
